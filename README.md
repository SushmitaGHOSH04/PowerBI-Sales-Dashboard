# PowerBI-Sales-Dashboard

📊 Project Overview
This project is an interactive Power BI dashboard developed to analyze sales performance using the Global Superstore dataset.
The dashboard presents sales information across different categories, states, regions, customers, products, shipping modes, and years. It transforms raw business data into an interactive visual report that can be used to identify sales trends and understand customer and product performance.

🎯 Objectives
Analyze overall sales performance.
Identify sales distribution across product categories.
Analyze sales across different states and regions.
Understand customer and product-level information.
Compare sales performance across different years.
Analyze shipping modes and customer distribution.
Present business information through interactive Power BI visualizations.

🛠️ Tools & Technologies
Microsoft Power BI
Power Query – data cleaning and transformation
DAX – calculations and measures
Data Visualization – charts, cards, tables, maps, and interactive visuals
Global Superstore Dataset

Sales by Year
Customer distribution by Category
Order Date/Product Name analysis

📈 Business Insights
The dashboard provides a consolidated view of:
Sales performance across multiple product categories.
Geographic variation in sales across states and regions.
Year-wise changes in sales.
Distribution of customers across different regions.
Category-level customer distribution.
Product and customer-level transaction details.
Shipping mode information and its relationship with orders.

🖥️ Dashboard Preview
